GitHub Access Token

To save concerts to the website, the admin needs a GitHub Personal Access Token.
Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
Scope it to the -site repo with Contents: Read and Write.
This only needs to be done once per device.
